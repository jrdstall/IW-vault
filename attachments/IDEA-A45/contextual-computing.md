# contextual computing

I keep re-hashing this idea:

- Code is no longer something you buy.  Code is no longer something that is static.  With AI, you can now create in seconds basic code to do things that the averable person before couldn't do because they didn't have the skillsets, or even if you did have the skillset it would take too much of your limited time.

- Because of how things worked the past and becuase of the need to monetize work, apps became the basic unit of currency.

Now, anyone can create software, that can be something they use for a while, or can be something used to answer a dynamic, one-time question.

So, what becomes of the traditional app-based economy?  Do we need to keep it?  What is possible?

I think to see what's truly possible, we have to give up our pre-conceived notions of how things work.  we have devices with operating systems with drivers for I/O devices, and then we have apps that we put on them, that we pull down from trusted stores (Google, Windows, Apple App stores).  

We should be thinking we have processing capability, we have IO capabilities (screens, speakers, microphones, keyboards, mouse, cameras, wearables, etc), we have services like real-time location, or other services we buy like budgeting and accounting, health tracking, etc., we have IoT sensors and effectors. 

 We have content and data (like media - entertainment, learning, books, videos, social media, articles, blogs, etc.).  We have data we can generate about ourselves or our business, and we have data we can buy or access about our world, about other people, or whatever.  A world of data.  

In a business setting it is similar, we have the same kinds of things, but data about our business, supply chain, facilities, accounting, HR, customers, competetitors, the business and financial markets, etc.

In a Defense seting similar categories, but more interesting and fun stuff.  We have red force and blue force data, we have all kinds of sensors and effectors, we have military doctrine, ROE, COAs, TTPs, we have real time tracks and status, we have intelligence, we have all kinds of IoT sensors, we have all kinds of IO devices for the warfighter.

It seems to me, this simple use case is a single exmaple:

If all these things were not so app and OS driven, but all lived with in a core ecosystem, and the AI could respond to user requests and task and in real-time  have it create the glue code that brings together the data, services, sensors, effectors and IO to complete the user request in real-time, or create personalized services and capabilities that are reused.  For example, I go back to the simple exmaple, if I had a simple eInk IO device mounted in the kitchen, and i find a recipe, and say "push this to the kitchen eInk display" and without having to have a priori installed and configured apps on my phone and on the eInk display that had this feature built in, but rather in real-time the AI took the data i wanted, found the IO device, and wrote a quick script or called a simple discoverable "display" functoin and pushed the content.  Then after eating dinner, I realized the sauch wasn't spicy enough, and i told AI to save that recipe in my personal data archive and add a note to double the cayenne pepper next time, and this was all done without having pre-built or installed apps and etc.

That simple use case expands to this larger world - where the economy that is monetized is not data, and core services that do heavy lifting tasks, but expose themselves with machine-to-machine interfaces and now we let AI basically discover and use our services and our content and our data and our IoT and our IO to do whatever we ask in real-time.  

In a defense setting, the example is we have core services that do the things that need to be repeatable and verifiable (like physics modeling of a satellite in orbit) but expose that service to allow AI to query it when a user asks about upcoming opportunities or whatever.


So here are my questions:

what would this new "Contextual computing" environment look like?  Can we create generic building blocks like processors, IO, Data, Services and throw away our traditional OS, device, app model?  it's like fractionating things and making the building blocks a layer lower than apps. 

can we build a prototype that shows how this could work, for a personal, for a business and for a defense setting?  What would be build, what could it show, how much would it cost?  How much code would have to be written?  would we have to emulate or simulate some of this given current platforms aren't designed for this?

Is this worth trying to build such a prototpye?

What would it take to move up the CML models from my current CML level 1 to CML level 4?
